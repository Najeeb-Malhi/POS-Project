# 🛒 Point of Sale (POS) System

A Python-based **Point of Sale (POS) system** developed for a grocery store to manage inventory, stock, billing, invoices, discounts, and sales reporting through a graphical user interface.

Although this is a student-developed desktop application, the project focuses on implementing **real-world business rules, input validation, inventory controls, and error prevention** rather than simply demonstrating basic Python functionality.

## 📌 Project Overview

Managing a small grocery store involves more than simply adding products and calculating prices. Incorrect pricing, invalid stock quantities, accidental data changes, and billing errors can all cause problems.

This POS system was designed with these practical considerations in mind.

The application provides dedicated controls for common store operations, including:

* Adding products to inventory
* Removing products from inventory
* Updating product stock
* Monitoring low-stock products
* Generating customer bills
* Applying discounts
* Generating invoices
* Tracking sales
* Calculating monthly profit
* Storing inventory and sales data

The system also includes validation rules to prevent logically incorrect data from entering the system.

#  Key Features

## 📦 Inventory Management

The system provides functionality to manage products within the store inventory.

Users can:

* Add new products
* Remove existing products
* Update product stock
* View inventory information
* Monitor product quantities
* Manage product pricing

### 🔴 Low-Stock Detection

Products with a quantity of **less than 10** are automatically highlighted in red, making it easier to identify products that need restocking.

This provides a simple visual indication of inventory that requires attention.

---

## 🛡️ Input Validation & Business Rules

The application contains validation mechanisms designed to prevent invalid or logically inconsistent information from being entered.

For example:

> **Sale Price must be greater than the Cost Price.**

The system validates this condition before accepting the product information.

These checks help prevent incorrect pricing data and reduce the possibility of invalid transactions.

The application also uses validation for other relevant inputs and operations to make the system more reliable.

---

##  Billing System

The POS system allows products to be selected and added to a customer's bill.

The billing functionality includes:

* Adding products to the bill
* Managing quantities
* Calculating the bill
* Applying discounts
* Generating the final invoice

The system handles the calculations automatically, reducing the need for manual calculations during a transaction.

---

## 🏷️ Discount Support

Discounts can be applied when generating a bill.

The system incorporates the discount into the final billing calculation so that the customer receives the correct final amount.

---

## 🧾 Invoice Generation

After completing a transaction, the system generates an invoice.

Invoices are stored as **`.txt` files**, allowing previous transactions to be retained as individual invoice records.

Example:

```text
Bill_1.txt
```

The invoice contains the relevant transaction information generated by the POS system.

---

## 📊 Monthly Sales & Profit Reports

The system can generate a **monthly sales report** containing information about the store's sales performance.

The report can provide information such as:

* Products sold
* Total sales
* Monthly profit

This allows the store owner to get a basic overview of business performance without manually calculating sales figures.

---

# 💾 Data Storage

The application uses different file formats for different types of data.

### JSON

Inventory and sales/report information are stored using JSON files.

```text
inventory.json
report.json
```

JSON provides a simple way to maintain structured data while keeping the project lightweight and easy to manage.

### TXT

Invoices are generated and stored as text files.

```text
Bill_1.txt
```

This separation allows inventory/report data and individual invoices to be maintained independently.

---

# Graphical User Interface

The application uses **Python Tkinter** to provide a graphical interface.

Instead of relying on command-line inputs, the system provides dedicated buttons and controls for different operations.

Examples include:

* Add Product
* Remove Product
* Update Stock
* Add to Bill
* Generate Bill
* Apply Discount
* Generate Report

This makes the application easier to use for someone who may not have programming knowledge.

# 🚀 Getting Started

## Prerequisites

Install Python on your computer.

Check your Python installation:

```bash
python --version
```

The project primarily uses Python's built-in functionality, including Tkinter and JSON/file-handling libraries.

## Running the Application

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd POS-System
```

Run the application:

```bash
python main.py
```

> Replace `main.py` with the actual entry-point filename if your project uses a different filename.
